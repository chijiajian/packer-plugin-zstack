These examples require plugin v1.2.0 or later with `zstack-iso` support. Run `packer init` to install the release selected by each template. Supply variables through a local ignored `.pkrvars.hcl` file or `PKR_VAR_*` environment variables, and use the normal `ZSTACK_*` credentials.

The Debian BIOS boot command loads Preseed from Packer's HTTP server. The auxiliary CD contains `post-install.sh`; Preseed mounts `/dev/sr1` and runs that script in the installer to configure target SSH and completion markers. Change disk/CD device names for your VM hardware. This is an installer script, not a ZStack userdata payload.

Debian 13's `apt-cdrom` automatically scans all optical drives. The Preseed early command installs an APT generator that temporarily sets `Acquire::cdrom::AutoDetect "false"`, so the answer CD is not mistaken for a package repository. The late script removes that temporary APT configuration. Without this, the installer can stop at an interactive APT media error even though the answer file was read correctly.

Verify the installation ISO against the Debian publisher's checksum before serving its URL. Set `http_ip` to an address reachable from both the VM and backup storage. Generated CDs must be downloadable from the runner's temporary publisher port, and the runner must reach the host's TCP VNC console. BIOS/UEFI installers have different boot menus; this example's boot command targets BIOS.

`installation_check_command` verifies the late script's markers and an ext4 root filesystem before and after the builder detaches both ISOs and restarts from hard disk. The example keeps the installation root credential for provisioning; apply your credential removal/rotation and image generalization policy in final provisioners.

Additional answer-file fixtures:

- `rocky.ks.pkrtpl`: Rocky Linux 9 minimal ISO, Kickstart over HTTP, root SHA-512 password hash. ARM64 GRUB can load `/images/pxeboot/vmlinuz` with `inst.ks=http://{{ .HTTPIP }}:{{ .HTTPPort }}/ks.cfg inst.stage2=hd:LABEL=Rocky-9-4-aarch64-dvd ip=dhcp console=tty0`, then `/images/pxeboot/initrd.img` and `boot`. Match the ISO volume label and use `boot_mode = "UEFI"` for the ARM fixture.
- `ubuntu-autoinstall.pkrtpl`: Ubuntu Server 24.04 Subiquity autoinstall. Put rendered content in `cd_content["user-data"]`, an instance ID in `cd_content["meta-data"]`, and set `cd_label = "cidata"`. GRUB loads `/casper/vmlinuz autoinstall ds=nocloud ---`, then `/casper/initrd` and `boot`. Connect as `packer` using the password matching `password_hash`. This uses Ubuntu's installer NoCloud reader on the CD; ZStack userdata is not involved.
- `windows-Autounattend.xml.pkrtpl`: Windows Server 2022 AMD64, UEFI/GPT, image index 2. Provide the installation administrator password as XML-escaped `admin_password_xml` and the reachable runner address as `winrm_client_address`. Put the answer XML at the CD root as `Autounattend.xml`, copy `windows-setup.ps1` as `setup.ps1`, and copy `windows-verify-install.ps1` as `verify-install.ps1`. Add signed Server 2022 VirtIO `viostor`, `vioscsi` and `NetKVM` driver directories under `drivers/`; these external binaries are not committed. The fixture assumes installer CD D: and answer CD E:. Use HTTPS WinRM/NTLM; the setup script restricts the firewall to the runner address. Send Enter after the boot-prompt keys so Windows Boot Manager does not remain paused. Use a root disk of at least 60 GiB and 4 GiB RAM.

For UEFI Debian, GRUB loads `/install.amd/vmlinuz` with the same Preseed arguments, then `/install.amd/initrd.gz` and `boot`; `/install.a64/` is the corresponding Debian ARM installer directory. Set `boot_mode = "UEFI"` and include `test -d /sys/firmware/efi` in the installation check. The Windows verification script checks the firmware through `GetFirmwareType`, the OS caption and AMD64 architecture.

The fixtures intentionally enable installation credentials for acceptance. Supply private values through ignored files, apply your credential policy before distributing images, and perform Windows generalization separately when needed. Real environment acceptance covered Debian 13.7 amd64 (BIOS and UEFI), Ubuntu Server 24.04 LTS amd64 UEFI, Rocky Linux 9.4 ARM64 UEFI, and Windows Server 2022 amd64 UEFI. Each run verified unattended installation, hard-disk reboot, SSH/WinRM file transfer, output-template boot, export deletion and resource cleanup.
